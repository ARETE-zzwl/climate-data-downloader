# 气候数据下载器功能说明

这是一款面向 Windows 用户的图形化气候数据检索、下载和整理工具。它适合科研、规划、农业、水文、生态、能源等场景中需要批量获取 NetCDF 气候数据的用户。

本文对应 0.2.0；新增功能操作、数据含义和限制见 [升级说明](升级说明_0.2.0.md)。

一句话卖点：把分散在 NASA、ESGF、DKRZ、NOAA 等官方平台上的气候数据，变成“可勾选、可预览、可批量下载、自动整理成数据包”的桌面软件。

## 当前支持的数据源

| 数据源 | 状态 | 说明 |
|---|---:|---|
| NEX-GDDP-CMIP6 | 可用 | NASA NEX 全球降尺度日尺度情景数据，常用 0.25° 网格 |
| CMIP6 原始模式数据 | 可用 | 通过 LLNL ESGF 官方联合索引检索原始模式文件 |
| CORDEX | 可用 | 通过 DKRZ ESGF 官方索引检索区域气候模式数据 |
| NASA POWER | 可用 | 通过 NASA POWER 官方 API 下载气象与太阳能 NetCDF 数据 |
| NOAA CPC | 可用 | 全球陆地逐日降水分析，0.5°，1979 年起 |
| NCEP/NCAR | 可用 | 逐日再分析气温（sigma=0.995，非 2 米）及海平面气压，2.5°，1948 年起 |
| ERA5 / ERA5-Land | 预留 | 需要用户自己的 Copernicus CDS 账号、许可证确认和 API key |

## 可选维度

### NEX-GDDP-CMIP6

- 模式：如 `ACCESS-CM2`、`CanESM5`、`MIROC6`、`MPI-ESM1-2-HR` 等。
- 情景：`historical`、`ssp126`、`ssp245`、`ssp370`、`ssp585`。
- 成员：常用 `r1i1p1f1`。
- 变量：`hurs`、`huss`、`pr`、`rlds`、`rsds`、`sfcWind`、`tas`、`tasmax`、`tasmin`。
- table：默认 `day`。
- 版本：`v2.0`、`v1.1`、`original`。
- 时间：起始年、结束年。
- 空间：全球或自定义经纬度矩形。

### CMIP6

- 模式、试验、成员、变量、table 均支持多选。
- 可通过“刷新官方可选项”从 ESGF 获取当前候选列表。
- 支持按年份范围过滤文件。

### CORDEX

- 区域域：如 `SEA-22`、`EUR-11`、`EAS-22`、`AFR-22` 等。
- 驱动模式、区域模式 RCM、试验、成员、变量、频率均支持多选。
- RCM 支持“不限”，用于兼容部分官方记录缺少 RCM facet 的情况。

### NASA POWER

- 变量：`T2M`、`T2M_MAX`、`T2M_MIN`、`PRECTOTCORR`、`RH2M`、`WS2M`、`ALLSKY_SFC_SW_DWN`。
- 时间尺度：`daily`、`monthly`。
- 空间：自定义经纬度矩形；区域接口要求经度跨度和纬度跨度都至少 2°。

## 下载和整理能力

- 下载前预览文件清单、大小、来源和筛选组合。
- 支持并发下载、失败重试和断点续传。
- 下载前保存任务计划，支持暂停以及关机后选择原数据包恢复；同一数据包禁止多实例同时写入。
- 支持系统代理/直连切换，显示下载速度、连接与重试日志。
- 下载后自动整理为标准数据包。
- `manifest.json` 记录筛选条件、处理参数、官方 URL、文件大小和本地路径。
- `checksums.sha256` 用于校验本地文件完整性。
- `reports/failed_items.csv` 记录失败项目，便于补下载。

NOAA 数据源可选变量、起止年份、输出区域和后处理尺度；它们没有 SSP 情景或多模式成员。失败的查询组合不在已解析的文件计划中，应按报告重新查询，不能仅靠恢复已有清单补全。

## 后处理能力

- 经纬度矩形裁剪。
- 输出网格间距设置。
- 时间尺度转换：保持原始、日、月、年。
- 聚合方式：平均、求和、最小、最大。

注意：重采样只改变输出网格间距，不会提高源数据本身的物理精度。区域裁剪和重采样在完整文件下载后本地执行，因此大任务仍需要预留足够磁盘空间。

## 批量下载能力

批量任务使用 JSON 配置文件，支持把模式、情景、变量等多选项展开成多个组合。

示例：

```json
{
  "dataset": "nex",
  "models": ["MPI-ESM1-2-HR"],
  "experiments": ["ssp126", "ssp245", "ssp585"],
  "members": ["r1i1p1f1"],
  "variables": ["tas", "pr"],
  "tables": ["day"],
  "version": "v2.0",
  "years": [2025, 2025],
  "output": "downloads/nex_batch_example",
  "workers": 3,
  "keep_raw": true
}
```

运行：

```powershell
.\ClimateDataDownloaderCLI.exe batch --config .\examples\nex_batch_dry_run.json --dry-run
```

## 商业交付注意事项

本软件可以作为下载和整理工具销售，但气候数据本身来自第三方官方数据源。销售、演示或交付时应明确：

- 软件不声称拥有官方数据版权。
- 用户下载和使用数据需遵守各数据源许可证、引用和使用条款。
- CMIP6/CORDEX 中不同模式机构可能有不同引用或许可要求。
- ERA5/ERA5-Land 需要用户自行配置 Copernicus CDS 账号和授权。

## 适合与不适合的客户

适合：

- 需要批量下载 NEX-GDDP-CMIP6、CMIP6、CORDEX、NASA POWER 数据的科研和工程用户。
- 不想手写 ESGF / NASA API 脚本的用户。
- 需要自动整理数据包、manifest、checksum 和失败报告的用户。

不适合：

- 完全不具备基础气候数据概念、希望软件代替专业判断的用户。
- 需要内置付费数据或专有数据的用户。
- 需要 ERA5 自动授权下载且不愿提供自己 CDS 账号的用户。
