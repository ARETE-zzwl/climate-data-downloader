# 气候数据下载器功能说明

气候数据下载器是一款面向 Windows 用户的图形化气候数据检索、下载和整理工具。它适合科研、规划、农业、水文、生态、能源等场景中需要批量获取 NetCDF 气候数据的用户。

## 一句话卖点

把分散在 NASA、ESGF、DKRZ、NASA POWER 等官方平台上的气候数据，变成“可勾选、可预览、可批量下载、自动整理成数据包”的桌面软件。

## 当前支持的数据源

| 数据源 | 状态 | 说明 |
|---|---:|---|
| NEX-GDDP-CMIP6 | 可用 | NASA NEX 全球降尺度日尺度气候情景数据，常用 0.25° 网格 |
| CMIP6 原始模式数据 | 可用 | 通过 LLNL ESGF 官方联邦索引检索原始模式文件 |
| CORDEX | 可用 | 通过 DKRZ ESGF 官方索引检索区域气候模式数据 |
| NASA POWER | 可用 | 通过 NASA POWER 官方 API 下载气象与太阳能 NetCDF 数据 |
| ERA5 / ERA5-Land | 预留 | 需要用户自己的 Copernicus CDS 账号、许可确认和 API Key，当前版本不读取或保存凭据 |

## 可选维度

### NEX-GDDP-CMIP6

- 模式：如 ACCESS-CM2、CanESM5、MIROC6、MPI-ESM1-2-HR 等
- 情景：historical、ssp126、ssp245、ssp370、ssp585
- 成员：r1i1p1f1
- 变量：hurs、huss、pr、rlds、rsds、sfcWind、tas、tasmax、tasmin
- 版本：v2.0、v1.1、original
- 时间：起始年、结束年
- 空间：全球或自定义经纬度矩形

### CMIP6

- 模式、试验、成员、变量、table 均支持多选
- 可通过“刷新官方可选项”从 ESGF 获取当前候选列表
- 支持按年份范围过滤文件

### CORDEX

- 区域域：如 SEA-22、EUR-11、EAS-22、AFR-22 等
- 驱动模式、区域模式 RCM、试验、成员、变量、频率均支持多选
- RCM 支持“不限”，用于兼容部分官方记录缺少 RCM facet 的情况

### NASA POWER

- 变量：T2M、T2M_MAX、T2M_MIN、PRECTOTCORR、RH2M、WS2M、ALLSKY_SFC_SW_DWN
- 时间尺度：daily、monthly
- 空间：自定义经纬度矩形；NASA POWER 区域接口要求经纬度跨度都至少 2°

## 下载和整理能力

- 下载前预览文件清单、大小、来源和所属筛选组合
- 支持并发下载、失败重试和断点续传
- 下载后自动整理为标准数据包：

```text
climate_package_YYYYMMDD_HHMMSS/
├─ README.txt
├─ manifest.json
├─ checksums.sha256
├─ raw/
├─ processed/
└─ reports/
```

- `manifest.json` 记录筛选条件、处理参数、官方 URL、文件大小和本地路径
- `checksums.sha256` 可用于校验本地文件完整性
- `reports/failed_items.csv` 记录失败项目，便于补下载

## 后处理能力

- 经纬度矩形裁剪
- 输出网格间距设置
- 时间尺度转换：保持原始、日、月、年
- 聚合方式：平均、求和、最小、最大

说明：重采样只改变输出网格间距，不会提高源数据本身的物理精度。区域裁剪和重采样在完整文件下载后本地执行，因此需要预留足够磁盘空间。

## 商业交付注意事项

本软件可以作为下载和整理工具销售，但气候数据本身来自第三方官方数据源。销售、演示或交付时应明确：

- 软件不声称拥有官方数据版权
- 用户下载和使用数据需遵守各数据源许可、引用和使用条款
- CMIP6/CORDEX 中不同模式机构可能有不同引用或许可要求
- ERA5/ERA5-Land 需要用户自行配置 Copernicus CDS 账号和授权
