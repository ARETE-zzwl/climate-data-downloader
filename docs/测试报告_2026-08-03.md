## 已知限制

- ERA5 / ERA5-Land 仅预留入口，尚未实现凭据配置和 CDS API 下载。
- 图形界面是 Tkinter 桌面界面，外观偏工具型；如果面向非技术客户销售，后续可升级品牌化界面。
- 当前发布包仍依赖用户本机安装 Python 3.10+。若要“一键安装无需 Python”，建议后续制作 PyInstaller / Inno Setup / MSIX 安装包并做代码签名。
- 大批量气候数据下载依赖第三方官方站点，速度和可用性会受官方服务、网络和节点镜像影响。
