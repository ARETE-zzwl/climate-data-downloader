## 已修复的发布问题

第一次 PyInstaller 便携包 GUI 启动失败，原因是 Tcl/Tk 脚本库与 DLL 版本不一致：

```text
init.tcl: version conflict for package "Tcl": have 8.6.10, need exactly 8.6.12
```

已在 `Build_Portable_App.ps1` 中修复：构建时从当前 Python 查询真实 Tcl/Tk 运行时路径，并显式把匹配版本的 Tcl/Tk 脚本库和 DLL 复制进最终便携包。
