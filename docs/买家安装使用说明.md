# 气候数据下载器：买家安装使用说明

适用软件包：

```text
ClimateDataDownloader_0.2.0_portable_*.zip
```

如果你收到的文件名略有不同，只要包含 `portable`，一般就是免 Python 便携版。

## 1. 使用前准备

- 支持系统：Windows 10 / Windows 11。
- 不需要安装 Python。
- 需要稳定网络连接。
- 气候数据文件通常较大，建议磁盘至少预留 50 GB；如果要下载多年、多模式、多变量数据，建议预留 100 GB 以上。

## 2. 解压软件

收到 ZIP 文件后，右键选择：

```text
全部解压
```

建议解压到普通目录，例如：

```text
D:\ClimateDataDownloader
```

注意：

- 不要直接在压缩包里双击运行。
- 不要只把 `ClimateDataDownloader.exe` 单独拖出来运行。
- 必须保留整个解压后的文件夹结构，尤其是 `_internal` 文件夹。

## 3. 启动软件

进入解压后的文件夹，双击：

```text
ClimateDataDownloader.exe
```

如果 Windows 弹出“Windows 已保护你的电脑”或类似安全提示：

1. 点击“更多信息”。
2. 点击“仍要运行”。

这是因为当前版本尚未做 Windows 代码签名。请确认安装包来自卖家本人后再运行。

## 4. 基本下载流程

打开软件后，按下面步骤操作：

1. 选择数据源，例如：
   - NEX-GDDP-CMIP6
   - CMIP6
   - CORDEX
   - NASA POWER
   - NOAA CPC（陆地逐日降水）
   - NOAA NCEP/NCAR（逐日再分析）

2. 选择筛选条件，例如：
   - 模式
   - 情景 / 试验
   - 成员
   - 变量
   - 时间范围
   - 空间范围

3. 如果需要区域数据：
   - 取消“全球范围”。
   - 填写经纬度范围。

4. 选择输出目录。

5. 点击“查询清单”。
   - 先确认文件数量、文件大小和筛选条件。
   - 建议第一次先选少量年份和少量变量测试。

6. 确认无误后，点击“下载并整理”。

7. 下载完成后，软件会在输出目录生成一个数据包文件夹。

### 暂停和关机后继续

点击“暂停”会保留已下载部分；正在等待网络时，需要等读取结束或超时。下次打开软件，点击“恢复任务…”并选择原来的 `climate_package_*` 文件夹（其中应有 `task.json`），即可继续原任务。不要重复点击“下载并整理”，那会建立新数据包。

“范围与输出”中可以切换系统代理/直连。速度长时间不变时，先查看连接、重试或处理日志，再暂停并尝试另一连接方式。旧版没有 `task.json` 的任务不能直接使用这一恢复入口。

## 5. 下载结果在哪里

每次下载任务会生成类似下面的文件夹：

```text
climate_package_YYYYMMDD_HHMMSS
```

数据包结构一般如下：

```text
climate_package_YYYYMMDD_HHMMSS/
├─ task.json
├─ README.txt
├─ manifest.json
├─ checksums.sha256
├─ raw/
├─ processed/
└─ reports/
```

各文件夹和文件含义：

- `raw/`：官方原始数据。
- `task.json`：保存下载清单和处理设置，用于恢复任务，请勿手动改动。
- `processed/`：裁剪、重采样或时间聚合后的数据。
- `manifest.json`：下载清单、筛选条件、来源 URL。
- `checksums.sha256`：文件完整性校验码。
- `reports/download_report.json`：下载报告。
- `reports/failed_items.csv`：失败清单。

如果只下载原始数据，重点查看 `raw/`。

如果设置了裁剪、重采样或时间聚合，重点查看 `processed/`。

## 6. 建议的新手测试方法

第一次使用时，建议先做小任务测试：

- 时间范围只选 1 年。
- 变量只选 1 个。
- 模式只选 1 个。
- 空间范围尽量选择较小区域。

建议选择 NCEP/NCAR、变量 `air`、2020 年作为小样本，原文件约 7 MB。多数数据源的区域裁剪在完整文件下载后执行，缩小区域并不会缩小原始下载量。`air` 是 sigma=0.995 近地面气温，不是标准 2 米气温。

确认下载和整理正常后，再扩大年份、变量和模式范围。

## 7. 批量下载，高级用户可用

软件包中还包含命令行批量下载工具：

```text
ClimateDataDownloaderCLI.exe
```

示例配置文件在：

```text
examples
```

例如运行 NASA POWER 小样本批量下载：

```powershell
ClimateDataDownloaderCLI.exe batch --config examples\power_batch_small.json --output downloads\power_test
```

只查询清单、不下载：

```powershell
ClimateDataDownloaderCLI.exe batch --config examples\nex_batch_dry_run.json --dry-run
```

普通用户如果不熟悉命令行，可以只使用图形界面。

## 8. 常见问题

### 双击软件没反应怎么办？

请确认：

- 已经完整解压 ZIP。
- 没有把 exe 单独复制出来。
- `_internal` 文件夹仍在软件目录内。
- Windows 安全提示已选择“仍要运行”。

### 为什么下载很慢？

气候数据来自 NASA、ESGF、DKRZ 等官方站点或官方公开镜像，文件通常很大。下载速度受官方服务器、网络环境和文件大小影响。

建议先下载小范围数据测试，再进行大批量下载。

### 下载失败怎么办？

可以查看：

```text
reports\failed_items.csv
```

里面会记录失败文件。常见原因包括网络中断、官方站点临时不可用、文件过大或筛选组合不存在。

### NASA POWER 区域数据报错怎么办？

NASA POWER 区域接口要求经度和纬度跨度都至少 2°。

例如下面是有效的小测试范围：

```text
经度：116 到 118
纬度：38 到 40
```

### ERA5 / ERA5-Land 为什么不能直接下载？

当前版本只预留 ERA5 / ERA5-Land 入口。正式下载需要用户自己的 Copernicus CDS 账号、许可证确认和 API key。

## 9. 数据来源说明

本软件是气候数据下载与整理工具，数据来自第三方官方数据源或官方公开镜像，例如 NASA、ESGF、DKRZ、NASA POWER 等。

用户下载和使用数据时，应遵守对应数据源的许可、引用和使用要求。

软件本身不声称拥有第三方气候数据版权。

## 10. 售后沟通时请提供的信息

如果使用中遇到问题，请尽量提供：

1. 软件包文件名。
2. 操作系统版本。
3. 选择的数据源和筛选条件。
4. 输出目录里的 `reports/download_report.json`。
5. 如果有失败文件，请提供 `reports/failed_items.csv`。
6. 截图或错误提示文字。

这样可以更快定位问题。
