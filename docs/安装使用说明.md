# 安装使用说明

## 版本选择

### 普通用户：使用免 Python 便携包

推荐交付文件：

```text
ClimateDataDownloader_0.1.0_portable_YYYYMMDD_HHMMSS.zip
```

使用方法：

1. 解压 ZIP 到普通目录，例如 `D:\ClimateDataDownloader`。
2. 双击 `ClimateDataDownloader.exe` 启动图形界面。
3. 如需运行批量任务，双击 `Run_Power_Batch_Demo.bat` 或在 PowerShell 中运行 `ClimateDataDownloaderCLI.exe batch ...`。

该版本不要求用户电脑安装 Python。

### 技术用户：使用源码安装包

源码安装包仍要求用户电脑安装 Python 3.10+。适合已有 Python 环境、需要二次开发或需要自己安装依赖的用户。

1. 安装 Python 3.10 或更高版本，并勾选 `Add Python to PATH`。
2. 解压源码 ZIP。
3. 双击 `Install_Climate_Data_Downloader.bat`。
4. 安装完成后双击 `Start_Climate_Data_Downloader.bat`。

## 图形界面基本流程

1. 选择数据源。
2. 勾选模式、情景/试验、变量、成员、频率等筛选条件。
3. 设置年份范围。
4. 如需区域数据，取消“全球范围”，填写经纬度矩形。
5. 选择输出目录。
6. 点击“查询清单”，先核对文件数量和体量。
7. 点击“下载并整理”。
8. 任务完成后，在输出目录中查看自动生成的数据包。

## 批量下载流程

批量下载使用 JSON 配置文件，适合固定方案、售后脚本和大批量任务。

先预览：

```powershell
.\ClimateDataDownloaderCLI.exe batch --config .\examples\nex_batch_dry_run.json --dry-run
```

真实下载：

```powershell
.\ClimateDataDownloaderCLI.exe batch --config .\examples\power_batch_small.json --output .\downloads\power_batch_small
```

常用参数：

- `--config`：批量任务 JSON。
- `--output`：覆盖 JSON 中的输出目录。
- `--workers`：覆盖 JSON 中的并发数。
- `--dry-run`：只查询和规划，不下载文件。

## 数据包里有什么

- `raw/`：官方原始文件，按数据源和筛选条件分层。
- `processed/`：裁剪、重采样、时间聚合后的结果。
- `manifest.json`：完整下载清单和来源 URL。
- `checksums.sha256`：本地文件校验码。
- `reports/download_report.json`：任务报告。
- `reports/failed_items.csv`：失败清单。

## 常见问题

### 普通用户需要安装 Python 吗？

使用 `portable` 免 Python 包不需要。使用 `windows` 源码安装包才需要 Python 3.10+。

### 为什么还没有“一路下一步”的安装器？

当前已经完成 PyInstaller 免 Python 便携包。真正的安装向导还需要 Inno Setup 或 MSIX 打包，以及代码签名证书。构建脚本已经预留代码签名参数；安装器可以作为下一步发布形态。

### 下载很慢怎么办？

气候数据文件通常很大，速度受官方站点、镜像节点和网络环境影响。建议先小区域、小年份测试，再做大批量任务。

### NASA POWER 区域报错怎么办？

NASA POWER 区域接口要求经度和纬度跨度都至少 2°。例如 `[116, 118, 38, 40]` 是有效的小测试范围。

### ERA5 为什么不能直接下载？

当前版本只预留 ERA5 / ERA5-Land 入口。正式启用需要用户自己的 Copernicus CDS 账号、许可证确认和 API key，本软件当前不读取或保存这些凭据。
