# 安装使用说明

## 适用系统

- Windows 10 / Windows 11
- Python 3.10 或更高版本
- 稳定网络连接
- 足够磁盘空间：气候数据文件通常很大，建议至少预留 50 GB 以上；大批量任务建议预留 100 GB 以上

## 快速安装

1. 解压发布包到一个不含特殊权限限制的目录，例如：

   ```text
   D:\ClimateDataDownloader
   ```

2. 双击运行：

   ```text
   Install_Climate_Data_Downloader.bat
   ```

   或中文脚本：

   ```text
   安装气候数据下载器.bat
   ```

3. 安装完成后，脚本会询问是否立即启动软件。

## 启动软件

双击运行：

```text
Start_Climate_Data_Downloader.bat
```

或中文脚本：

```text
启动气候数据下载器.bat
```

## 基本使用流程

1. 选择数据源。
2. 勾选模式、情景、变量、成员、频率等筛选条件。
3. 设置年份范围。
4. 如需区域数据，取消“全球范围”，填写经纬度矩形。
5. 选择输出目录。
6. 点击“查询清单”，先核对文件数量和体量。
7. 点击“下载并整理”。
8. 任务完成后，在输出目录中查看自动生成的数据包。

## 数据包里有什么

- `raw/`：官方原始文件，按数据源和筛选条件分层
- `processed/`：裁剪、重采样、时间聚合后的结果
- `manifest.json`：完整下载清单和来源 URL
- `checksums.sha256`：本地文件校验码
- `reports/download_report.json`：任务报告
- `reports/failed_items.csv`：失败清单

## 常见问题

### 提示“未找到 Python”

请安装 Python 3.10 或更高版本，并在安装 Python 时勾选 `Add Python to PATH`。

### 安装依赖很慢

首次安装需要从 PyPI 下载依赖，网络慢时可能需要几分钟。建议使用稳定网络，必要时配置国内镜像源。

### 查询有结果但下载慢

气候数据文件通常很大，NEX-GDDP-CMIP6 的单个逐年变量文件可能达到数百 MB。建议先小范围、小年份测试，再批量下载。

### NASA POWER 区域报错

NASA POWER 区域接口要求经纬度跨度都至少 2°。例如经度 116–118、纬度 38–40 是有效的小测试范围。

### ERA5 为什么不能下载

当前版本只预留了 ERA5 / ERA5-Land 入口。正式启用需要用户自己的 Copernicus CDS 账号、许可确认和 API Key。

## 命令行检查

安装完成后，可在 PowerShell 中运行：

```powershell
.\.venv\Scripts\python.exe -m cmip_downloader --help
```

如果能显示帮助信息，说明软件包入口安装正常。
