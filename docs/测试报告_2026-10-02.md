## 性能观察与剩余边界

- CPC 下载到约 41 MB 时，下载 Python 进程观测峰值工作集为 37,662,720 字节（约 35.9 MiB）。这是单个下载任务的观测，不是所有场景的峰值或内存上限；另有约 4.5 MiB 的启动进程。
- 进度更新按文件合并，日志约保留最近 1000 行；后处理仍可能随区域和网格尺寸消耗较多内存。磁盘预检查不包含未知大小和全部后处理空间。
- 环境中 netCDF4 导入曾输出 NumPy `ndarray size changed` RuntimeWarning；该警告在升级前已存在。本轮读写与实际聚合通过，未将其当作失败，但商业交付仍建议固定并在干净环境复测依赖组合。
- 本轮没有逐一联网验证 CMIP6/CORDEX 所有节点，也未测试大规模 TB 级任务、所有日历、网络代理或 Windows 安全软件组合。
- 恢复针对已保存的文件清单；查询阶段失败的组合需按报告重新查询。ERA5/ERA5-Land 仍仅预留入口。
