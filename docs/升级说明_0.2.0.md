# 气候数据下载器 0.2.0

## 新增数据源

| 界面入口 | 变量及含义 | 原始尺度 | 年份 |
|---|---|---|---|
| NOAA CPC | `precip`，全球陆地雨量站分析降水；原始单位以文件属性为准（本轮 2020 样本为 mm） | 0.5°、逐日；按年一个文件 | 1979 年起 |
| NOAA NCEP/NCAR | `air`，sigma=0.995 近地面气温（K）；`slp`，海平面气压 | 2.5°、逐日；每变量每年一个文件 | 1948 年起 |

这两类属于观测分析/再分析产品，没有 SSP 情景和多模式成员。`air` 不是标准 2 米气温，勿与 NEX 的 `tas` 直接混用。未来年份不能下载；当前年份可能尚未发布或不完整，以预览查询和实际时间坐标为准。

官方入口与下载目录：

- [NOAA CPC 数据说明](https://psl.noaa.gov/data/gridded/data.cpc.globalprecip.html)
- [NCEP/NCAR 数据说明](https://psl.noaa.gov/data/gridded/data.ncep.reanalysis.html)
- [CPC 官方 NetCDF 目录](https://downloads.psl.noaa.gov/Datasets/cpc_global_precip/)
- [NCEP 逐日地表产品目录](https://downloads.psl.noaa.gov/Datasets/ncep.reanalysis.dailyavgs/surface/)

软件通过 HEAD 查询文件是否存在和实际大小，不用固定估计代替清单。完整年度全球文件先下载，再进行本地裁剪/重采样。缩小区域不减少原始下载量。

## 暂停与重启恢复

1. 查询清单并开始下载。任务开始时生成数据包和 `task.json`，日志显示所在目录。
2. 点击“暂停”。正在等待网络时，需要等当前读取返回或超时；正在处理/计算校验时，需要等当前步骤结束。
3. 点击“恢复任务…”并选择含 `task.json` 的原数据包目录。程序使用保存的文件清单和处理参数，跳过已完成文件，并续传 `.part` 文件。
4. 关闭程序、断电或关机后，仍使用同一个“恢复任务”入口。点击“下载并整理”会创建一个新任务。

恢复时可以调整并发数和连接方式，但不会悄悄修改原任务的区域/时间聚合参数。源站返回的续传位置必须匹配，否则报告错误并保留临时文件。服务器不支持 Range 时，会从头下载该未完成文件。

同一个数据包只能有一个写入任务；第二个实例会提示该包正在使用。锁在进程退出后自动释放。旧版 0.1.0 中断任务没有保存计划，不能仅凭一个目录猜出全部筛选条件，需要单独恢复。

完成的任务再次恢复，会验证已有 SHA256 清单。清单用于发现下载后数据变化，不等于官方签名；源站提供校验码时，下载层另外验证源站校验码。

CLI 示例：

```powershell
ClimateDataDownloaderCLI.exe batch --config examples\noaa_cpc.json --dry-run --direct
ClimateDataDownloaderCLI.exe resume --package "D:\data\climate_package_时间戳" --workers 2 --direct
ClimateDataDownloaderCLI.exe verify --package "D:\data\climate_package_时间戳"
```

## 下载状态与网络

“范围与输出”新增“连接方式”：

- 系统代理：遵循当前 Python/系统代理配置。
- 直连：本次程序请求绕过系统代理，不修改 Windows 网络设置。

CLI 使用 `--direct`，或对当前进程设置 `CLIMATE_DIRECT=1`。不自动替用户切换代理或关闭证书验证。

日志显示连接、重试和完成；状态栏显示累计下载量、近期速度。超过 30 秒未收到进度会显示等待提示，这也可能处于校验/处理阶段，应结合日志判断。网络读超时默认 30 秒，失败最多重试 2 次；超时不是整文件下载期限，也不能保证每种代理都在固定时间内返回。

## 内存和磁盘

- 下载使用至多 64 KiB 单次读取，收到可读数据即写盘；不会把整个气候文件放入内存。
- 进度缓冲只保留每个文件的最新值；不按每个数据块无限排队。界面日志约保留最近 1000 行。
- 磁盘空间检查覆盖清单里已知的剩余原始文件大小，并保留 64 MiB 余量。未知大小和后处理输出仍需要用户额外预留空间。
- `.part` 是可恢复的数据，不是无用缓存；下载成功后重命名为正式文件，不保留双份。
- 处理输出先写临时文件，完整写出后才替换正式结果。后处理仍可能使用较多内存，取决于网格、年份和重采样目标；大任务建议按年、按区域分批。
- 勾选保留原始文件时，`raw/` 与 `processed/` 都占磁盘。取消时，整个处理阶段成功后才删除原始文件；失败/暂停保留输入用于恢复。

时间聚合保留原变量单位，不自动把降水通量转换成累计毫米。尤其 NEX/CMIP6 的 `pr` 常见单位为 kg m-2 s-1；直接求和不能当作年降水毫米。
