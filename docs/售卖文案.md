## 商品详情页文案

### 你会遇到的问题

做气候数据分析时，最耗时间的往往不是分析本身，而是：

- 不同数据源入口分散，NEX、CMIP6、CORDEX、POWER 各有各的检索方式。
- 模式、情景、变量、成员、年份组合多，手动点选很容易漏。
- ESGF 或 NASA 链接需要反复查询，批量下载脚本不好写。
- 下载后的 NetCDF 文件散在不同目录里，后期整理很费时间。
- 需要裁剪区域、转换时间尺度、记录来源和失败文件，还要自己写代码处理。

### 这个工具解决什么

气候数据下载器把常用公开气候数据源整合到一个 Windows 图形界面里：

- 勾选数据源、模式、情景、变量、年份。
- 查询前先预览文件清单和体量。
- 支持多选组合批量展开。
- 支持并发下载、断点续传和失败记录。
- 下载后自动生成标准数据包。
- 自动保存 manifest、来源 URL、SHA256 校验码和下载报告。
- 可选择区域裁剪、空间重采样、日/月/年尺度聚合。

### 当前支持的数据源

### 下载结果自动整理

每次任务都会生成一个独立数据包：

```text
climate_package_YYYYMMDD_HHMMSS/
├─ raw/                  官方原始数据
├─ processed/            本地处理结果
├─ manifest.json         下载清单与来源 URL
├─ checksums.sha256      文件校验码
└─ reports/              下载报告与失败清单
```

这样后续做论文、项目归档、数据复现或交给同事时，都更清楚。

## FAQ 文案

### 需要安装 Python 吗？

免 Python 便携版不需要。解压后双击 `ClimateDataDownloader.exe` 即可。

### 数据源是官方的吗？

软件使用官方数据源或官方公开镜像入口，例如 NASA NEX、ESGF、DKRZ ESGF、NASA POWER。软件本身不拥有第三方数据版权。

### 下载结果是什么格式？

主要是 NetCDF 文件。下载完成后会自动整理为数据包，并附带 manifest、SHA256 校验码和下载报告。

### 可以批量下载吗？

可以。图形界面支持多选组合，命令行还支持 JSON 配置批量任务。

### 可以裁剪区域吗？

可以。软件支持自定义经纬度矩形，下载后进行本地裁剪和整理。
