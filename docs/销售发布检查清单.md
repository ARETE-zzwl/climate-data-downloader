## 免 Python 安装器路线

当前已经完成 PyInstaller 便携包。下一步可以做：

1. 安装 Inno Setup。
2. 用便携包目录作为安装器输入。
3. 生成 `ClimateDataDownloaderSetup_0.1.0.exe`。
4. 使用 OV/EV 代码签名证书签名安装器和两个 exe。
5. 在干净 Windows 10 / Windows 11 虚拟机中测试安装、卸载、桌面快捷方式和首次启动。

## 数据合规提醒

本软件是下载和整理工具，不应把第三方官方气候数据包装为自有数据资产。销售页、功能说明和交付文档中应明确数据来源、引用方式和许可边界。

## 推荐销售话术

适合：

- 需要批量下载 NEX-GDDP-CMIP6、CMIP6、CORDEX、NASA POWER 数据的科研和工程用户。
- 不想手写 ESGF / NASA API 脚本的用户。
- 需要自动整理数据包、manifest、checksum 和失败报告的用户。

谨慎销售：

- 完全非技术用户：建议等安装器、签名和更完整教程补齐后再大规模售卖。
- 需要 ERA5 自动登录和授权下载的用户：当前版本只预留入口。
- 希望软件内置付费数据或专有数据的用户：本软件只对接公开官方数据源。
