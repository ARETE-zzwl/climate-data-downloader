# 销售发布检查清单

## 当前可以交付的形态

- ZIP 发布包
- 用户解压后双击安装
- 安装后双击启动图形界面
- 下载结果自动整理为标准数据包

## 发布前必查

- [ ] 运行自动化测试
- [ ] 运行 GUI 启动测试
- [ ] 运行至少一个官方小样本下载测试
- [ ] 使用 `Build_Release_Package.ps1` 生成 ZIP
- [ ] 确认 ZIP 中不包含 `.venv`、`.git`、`downloads/`、测试下载数据
- [ ] 在干净目录解压 ZIP 并重新安装
- [ ] 确认 `python -m cmip_downloader --help` 可用
- [ ] 确认双击启动脚本可打开 GUI

## 商业销售前建议补齐

- [ ] 用户许可协议 / EULA
- [ ] 数据源许可与引用说明
- [ ] 隐私说明：软件不上传用户数据，不保存 ERA5/CDS 凭据
- [ ] 版本号、更新记录、售后支持邮箱或微信
- [ ] Windows 代码签名，减少杀毒软件误报
- [ ] 如果面向非技术用户，制作无需 Python 的安装器

## 数据合规提醒

本软件是下载和整理工具，不应把第三方官方气候数据包装为自有数据资产。销售页面和使用说明中应明确数据来源、引用方式和许可边界。

## 推荐销售话术

适合：

- 需要批量下载 NEX-GDDP-CMIP6、CMIP6、CORDEX、NASA POWER 数据的科研和工程用户
- 不想手写 ESGF / NASA API 脚本的用户
- 需要自动整理数据包、manifest、checksum 和失败报告的用户

不适合：

- 完全不具备基础气候数据概念的用户
- 需要 ERA5 自动登录和授权下载的用户
- 希望软件内置付费数据或专有数据的用户
